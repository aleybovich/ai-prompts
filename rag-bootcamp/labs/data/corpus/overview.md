# Nimbus Notes overview

Nimbus Notes is a note-taking and knowledge-management app for individuals and
teams. You write notes in Markdown, organize them into notebooks, link notes
together, and search across everything instantly.

Nimbus runs on macOS, Windows, Linux, iOS, Android, and in the browser. Notes
sync automatically across all your devices. You can also work fully offline; any
changes you make are synced the next time you come online.

Core ideas:

- **Notes** are Markdown documents. They can contain text, images, code blocks,
  checklists, and file attachments.
- **Notebooks** group related notes. A note lives in exactly one notebook.
- **Tags** cut across notebooks so you can find related notes no matter where
  they live.
- **Links** connect one note to another. Nimbus shows backlinks so you can see
  every note that points to the note you are reading.

Nimbus is built around fast, reliable search. The desktop and mobile apps keep a
local search index so results appear as you type, even offline.

Nimbus was first released in 2021 and is used by writers, students, engineers,
and support teams to keep their knowledge in one searchable place.
