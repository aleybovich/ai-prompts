# Sharing and collaboration

Nimbus Notes lets you share individual notes or whole notebooks with other
people.

## Sharing a single note

Open a note and click **Share**. You can create a read-only public link that
anyone can open in a browser without a Nimbus account. Public links can be turned
off at any time, and you can set an expiration date so the link stops working
after a chosen day.

## Sharing a notebook

You can invite specific people to a notebook by email. Each person is given one of
three permission levels:

- **Viewer** — can read notes but not change them.
- **Commenter** — can read notes and leave comments, but not edit the note body.
- **Editor** — can read, comment, and edit notes.

Invited people need a Nimbus account (Free is fine) to open a shared notebook.

## Real-time collaboration

When two or more people open the same note, Nimbus shows each person's cursor and
edits live, similar to a shared document editor. Changes merge automatically.
Comments appear in a side panel and can be resolved once addressed.

## Team notebooks

On the Team plan, an administrator can create **team notebooks** owned by the
organization rather than by an individual. Team notebooks support per-notebook
permissions and stay with the company even if the person who created them leaves.
This is the recommended way for companies to keep shared documentation.

## Sharing and encryption

You cannot create a public link for a note in an end-to-end encrypted notebook,
because the server cannot decrypt it to serve it in a browser. To share encrypted
notes, invite people to the notebook instead; they decrypt it locally.
